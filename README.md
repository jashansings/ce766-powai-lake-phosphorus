# Powai Lake phosphorus: final project (CE766, Jashanpreet Singh, 23B0985)

Annual water and phosphorus budget for Powai Lake, calibrated to observed lake TP
(Lekshmi et al., 2021), with NSGA-II direct policy search for sewage-phosphorus removal, 2026–2050.

**Data honesty note.** The rainfall series is synthetic (normal, mean 2,250 mm, s.d. 400 mm,
fixed seed). The rainfall and Sentinel-2 NDCI CSVs in the preliminary version of this repository
were also generated by a random-number generator and are not observations. Values marked
ASSUMED in `code/powai_model.py` are not measured for Powai.

## Reproduce (Python 3.11+, `pip install numpy scipy matplotlib pymoo==0.6.2`)

```bash
cd code
python3 powai_model.py                  # water/P budget and calibration printout
python3 optimize.py 1000                # first attempt: 25 open-loop annual values (did not converge)
python3 family_check.py                 # brute-force benchmark that exposed the non-convergence
python3 optimize_dps.py 1000 rbf        # second attempt: 2-RBF rule
python3 optimize_dps.py 1000 two_level  # final: 3-parameter two-level rule, 5 seeds
python3 family_check_dps.py             # benchmark vs final Pareto set
python3 robust_scan.py                  # re-evaluation over 500 sampled parameter sets (no PRIM)
python3 make_figures.py                 # final_policies.json + figures/
```

Outputs: `results/` (Pareto sets, convergence traces, benchmark and robustness JSON) and
`figures/figure1_budgets.png|pdf`, `figures/figure2_tradeoffs.png|pdf`.
